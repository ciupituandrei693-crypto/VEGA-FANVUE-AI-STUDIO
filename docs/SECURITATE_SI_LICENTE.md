# Reguli de securitate și licențe — VEGA

Repository-ul este **PUBLIC**. Conține exclusiv documentație tehnică nesensibilă, fără ZIP-uri-sursă, portrete personale, modele și conturi reale, chei sau tokenuri.

- Nu publica parole, OAuth refresh/access tokens, chei API, cookie-uri, date KYC, baze SQLite, fotografii private, materiale media personale, `.env` sau credențiale.
- Nu executa cod provenit din arhive înaintea auditului. Nu rula automat `npm install`, `pip install`, workflow-uri GitHub Actions sau containere necunoscute.
- Verificarea CRC/ZIP nu reprezintă un audit de securitate a codului.
- Verifică licențele exacte, inclusiv ale dependențelor, înainte de refolosire/distribuire.
- Postiz și VoiceStudio pot avea obligații AGPL; n8n are termeni specifici; FFmpeg poate fi compilat cu biblioteci și obligații diferite.
- Respectă drepturile asupra imaginilor/vocilor și marchează transparent personajele AI.
- Nu automatiza accesul la conturi fără OAuth sau permisiuni aprobate. Respectă limitele și regulile Fanvue/Meta/TikTok/X/Reddit.
- Publicarea materialelor cere aprobarea utilizatorului. Schimbările după aprobare o invalidează; Kill Switch blochează ieșirile.
- Fără achiziții, server extern sau GPU cloud fără aprobare explicită.

**Fără YouTube.** Separăm VEGA de celelalte proiecte JARVIS.
