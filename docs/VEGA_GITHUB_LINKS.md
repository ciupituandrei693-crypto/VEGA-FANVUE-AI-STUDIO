## Principii
- Next.js canary este doar sursă de referință; pentru aplicație alegem o versiune stabilă.
- Postiz și alte platforme similare pot avea dependențe și licențe complexe.
- n8n are condiții proprii de licențiere; nu îl tratăm automat ca licență open-source standard.
- Open-source ≠ GPU gratuit; testăm hardware-ul local.
- KoboldCpp este indisponibil și nu se instalează.
- Video-urile Research Scraps constituie idei pentru evaluare, nu audit al codului.
