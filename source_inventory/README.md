# Inventar arhive — păstrat local

Domenii acoperite: FastAPI, Next.js, n8n, Postiz, Instagram Agent Skill, Claude Content Skills, HyperFrames, FFmpeg, VoiceStudio, LatentSync și Ganache. **Ganache este doar inventariat, nu este necesar în VEGA.**

**Din motive de securitate și licențiere, arhivele, hashurile detaliate și copiile brute sunt păstrate în backupul privat/local, nu în acest repository public.** Nu există arhive sau cod terț executabil în această copie.
