# VEGA — FANVUE AI STUDIO

**Status: documentație de pregătire; dezvoltarea NU a început.** Acest repository este o copie publică, redusă la informații nesensibile. Nu conține arhivele ZIP originale, fotografii, codul aplicației, chei API sau datele conturilor.

## Obiectiv
Manager universal (iOS/iPhone, Android, Windows și web) pentru **9 modele AI**: Aria Vale, Maya Solis, Elena Hart, Nova Quinn, Selene Voss, Claudia Rose, Irina Sky, Liora Maren și Evelyn Frost.

- **Nivelul 2 — Automatizare supravegheată**: generare, SEO și planificare automate; publicare doar a materialelor aprobate, prin API-uri autorizate; Kill Switch și jurnal al acțiunilor.
- Platforme vizate: **Fanvue, Instagram, TikTok, X și Reddit**. **Fără YouTube.**
- Prioritate: **dezvoltare și testare complet locală pe Windows**, cu interfață PWA pentru telefon.
- **Ultima etapă**: conexiuni cu servicii de producție, server extern (~25 USD/lună) și GPU cloud (maximum 50 USD/lună), exclusiv cu aprobare expresă.
- **KoboldCpp nu este disponibil și este exclus din arhitectura activă.** Înlocuitorul se va decide la începutul dezvoltării.
- Păstrarea drepturilor asupra imaginilor, marcarea personajelor AI, KYC și respectarea regulilor platformelor sunt obligatorii.
